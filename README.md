# SQL-Sales-Data-Analysis
## Project Overview
Built an SQL project to analyze sales data and extract meaningful business insights using different SQL operations.

## Skills Used
- SQL
- Data Analysis
- Filtering
- GROUP BY
- JOIN
- Aggregate Functions
## SQL Concepts Implemented

- SELECT Statements
- WHERE Clause
- GROUP BY
- Aggregate Functions (AVG, SUM)
- INNER JOIN
## Project Output

- Identified top-selling products based on sales performance
- Analyzed category-wise sales distribution
- Filtered high-value sales records
- Calculated average sales amount using aggregate functions
- Connected customer and order data using JOIN operations
